# Changelog

- **Phase 1 (Skeleton + deploy):** React + Vite + TypeScript app with the ToothQBank layout shell (top bar with tooth logo, coming-soon home page, page-not-found page), settings file `src/config.ts`, ready for Cloudflare Pages.
- **Phase 2 (Database + auth):** Supabase tables with Row Level Security (questions readable only by approved students with the course unlocked, on their bound device, or admins), seed courses and General Medicine 1 chapters, phone-number sign-up and login, pending/rejected/revoked banners, one device per account.
- **Phase 3 (Course layout):** home page with Year → Semester → course cards (Unlocked / Locked with price and "How to unlock" / Coming soon), course page with sections and chapter list with progress, chapter page. Contact messages stay in `src/config.ts`.
- **Phase 4 (Admin dashboard):** `/admin` with Students (search, status filter with pending first, approve/reject/revoke/restore, course unlocks, device reset, password reset via a Cloudflare Pages Function, notes), Reports (preview, resolve/reopen), Import (checks the file, previews new/updated, imports all-or-nothing via `import_questions`) and Stats.
- **Phase 5 (Practice):** session builder (chapters with Select all, sections, Random / Most repeated first, number of questions), tutor mode with answer and explanation after each question, question screen ("Seen in X papers" badge, Previous/Next, navigator, flag, Report an error, copy protection), simple score at the end. Answers, flags and position are saved; the database marks answers correct or incorrect.
- **Phase 6 (Timed mode + progress):** timed sessions (30 sec–2 min per question, 1 min default, countdown, answers shown at the end, auto-finish when time is up), results page with a tappable review list (All / Incorrect / Unanswered / Flagged), builder filter (All / Unanswered / Incorrect only), resume or discard unfinished sessions and recent results on the course page, progress from the new `my_course_history` database function.
- **Phase 7 (Hardening):** security review (`docs/security-review.md`) with live read-only checks; migration 0004 (answers can only change on questions still open; Supabase helper function no longer callable); `/security-check` page that tests the rules with a locked test account; security headers (`public/_headers`); reload message for crashes and site updates; offline banner; log-in redirect for protected pages; "Questions locked" screen; narrow-phone top bar fix.
